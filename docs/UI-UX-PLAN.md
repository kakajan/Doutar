# پروژه دوتار | آلبوم «میراث صحرا» — Doutar

> نسخه: 1.0 — وضعیت: ✅ تکمیل شده (typecheck و build موفق)
> هدف: تبدیل لندینگ‌پیج فعلی به یک «تجربه شنیداری» روان، در دسترس و غنی از بازخورد، بدون تغییر در هویت بصری (شیشه‌ای طلایی/شنی، تایپوگرافی سینمایی، ذرات غبار).

## ۱. ممیزی وضعیت موجود (Audit)

| بخش | وضعیت | مشکلات شناسایی‌شده |
|---|---|---|
| هدر | ضعیف | فقط لوگو + دکمه دانلود؛ بدون منوی ناوبری، بدون منوی موبایل، بدون نوار پیشرفت اسکرول |
| صفحه اصلی | متوسط | MusicSection.vue (پخش آنلاین با تب) اصلاً استفاده نمی‌شود ← کاربر برای پخش حتماً باید وارد صفحه آلبوم شود |
| پلیر چسبان | متوسط | بدون کنترل صدا/بی‌صدا/تکرار، بدون اسپینر هنگام لود، زمان در موبایل پنهان است، بدون بازخورد بصری هنگام پخش |
| پلیر تمام‌صفحه | خوب اما ناقص | فقط Backspace بسته می‌شود (نه Escape)، بدون پلی‌لیست، بدون صدا، بدون دکمه دانلود/اشتراک، کاور ثابت است |
| کارت ترک | متوسط | بازخورد کپی با alert() مرورگر (شکسته‌کننده تجربه)، بدون مدت‌زمان، بدون اکولایزر هنگام پخش، متن اشتراک انگلیسی |
| دسترس‌پذیری | ضعیف | بدون focus-visible یکپارچه، بدون میان‌بر کیبورد، بدون skip-link، بدون focus trap در پلیر تمام‌صفحه |
| بازخورد | ضعیف | تنها بازخورد عملیات‌ها alert() است؛ بدون سیستم توست |

## ۲. استراتژی و اصول

1. **بازخورد فوری**: هر اقدام کاربر (کپی، دانلود، پخش، اشتراک) → توست غیرمزاحم.
2. **پخش بدون مانع**: کاربر از صفحه اول بتواند پخش کند (یکپارچه‌سازی MusicSection).
3. **کنترل کامل**: صدا، بی‌صدا، تکرار، جستجو، پلی‌لیست — همه‌جا در دسترس.
4. **دسترس‌پذیری واقعی**: کیبورد، فوکوس قابل‌مشاهده، کاهش‌حرکت، برچسب‌های ARIA.
5. **احترام به هویت بصری**: همه‌چیز در پالت طلایی/شنی و سبک شیشه‌ای فعلی.
